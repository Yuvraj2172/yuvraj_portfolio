# Yuvraj Soni — Portfolio

Personal portfolio site for Yuvraj Soni, Data Engineer, built with Next.js, TypeScript, and Tailwind CSS.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4
- [next-themes](https://github.com/pacocoursey/next-themes) for light/dark mode

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Project Structure

- `src/app` — pages, layout, and global styles
- `src/components` — page sections (Hero, About, Skills, Projects, Contact) and shared UI
- `src/lib/site-config.ts` — all site content (bio, skills, projects, contact links) in one place
- `src/hooks` — shared client-side hooks (scroll-spy nav)

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — run ESLint
